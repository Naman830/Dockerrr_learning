# 🐳 Docker Commands Cheat Sheet

This document contains the most commonly used Docker commands for managing Docker images and containers.

---

## 1. Pull a Docker Image

Downloads an image from Docker Hub to your local machine.

### Syntax

```bash
docker pull <image_name>
```

### Example

```bash
docker pull nginx
```

---

## 2. List Downloaded Images

Displays all Docker images available on your local system.

### Command

```bash
docker images
```

### Example Output

```text
REPOSITORY   TAG       IMAGE ID       CREATED       SIZE
nginx        latest    abc123xyz      2 weeks ago   192MB
```

---

## 3. Run a Container

Creates and starts a new container from an image.

### Syntax

```bash
docker run <image_name>
```

### Example

```bash
docker run nginx
```

> This starts the container using the default settings.

---

## 4. Run a Container in Interactive Mode

Starts a container and allows you to interact with it through the terminal.

### Syntax

```bash
docker run -it <image_name>
```

### Example

```bash
docker run -it ubuntu
```

### What `-it` Means

- `-i` → Keeps the terminal input open.
- `-t` → Allocates a terminal (TTY).

This is commonly used when working inside Linux containers.

---

## 5. Stop a Running Container

Stops a running container gracefully.

### Syntax

```bash
docker stop <container_name>
```

or

```bash
docker stop <container_id>
```

### Example

```bash
docker stop my-container
```

or

```bash
docker stop a1b2c3d4
```

---

## 6. Start an Existing Container

Starts a container that has already been created but is currently stopped.

### Syntax

```bash
docker start <container_name>
```

or

```bash
docker start <container_id>
```

### Example

```bash
docker start my-container
```

or

```bash
docker start a1b2c3d4
```

---

## 7. List Running Containers

Displays all currently running containers.

### Command

```bash
docker ps
```

---

## 8. List All Containers

Displays all containers, including stopped ones.

### Command

```bash
docker ps -a
```

---

## 9. Remove a Stopped Container

Deletes a stopped container from your system.

### Syntax

```bash
docker rm <container_name>
```

or

```bash
docker rm <container_id>
```

### Example

```bash
docker rm my-container
```

> **Note:** A container must be stopped before it can be removed.

---

## 10. Remove a Docker Image

Deletes an image from your local machine.

### Syntax

```bash
docker rmi <image_name>
```

or

```bash
docker rmi <image_id>
```

### Example

```bash
docker rmi nginx
```

> **Note:** You cannot remove an image if it is being used by an existing container.

---

## 11. List Docker Networks

Displays all Docker networks.

### Command

```bash
docker network ls
```

---

## 12. List Docker Volumes

Displays all Docker volumes.

### Command

```bash
docker volume ls
```

---

## 13. View Container Logs

Displays the logs generated by a container.

### Syntax

```bash
docker logs <container_name>
```

### Example

```bash
docker logs my-container
```

---

## 14. Execute a Command Inside a Running Container

Runs a command inside an already running container.

### Syntax

```bash
docker exec -it <container_name> <command>
```

### Example

```bash
docker exec -it my-container bash
```

If the container doesn't have `bash`, use:

```bash
docker exec -it my-container sh
```

---

## 15. View Detailed Information

Displays detailed information about a container or image.

### Container

```bash
docker inspect <container_name>
```

### Image

```bash
docker inspect <image_name>
```

---

## 16. View Running Processes Inside a Container

Shows the processes currently running inside a container.

### Command

```bash
docker top <container_name>
```

---

## 17. Download the Latest Version of an Image

Pulls the newest version of an image from Docker Hub.

### Command

```bash
docker pull <image_name>:latest
```

### Example

```bash
docker pull ubuntu:latest
```

---

## 18. Display Docker Version

Shows the installed Docker client and server version.

### Command

```bash
docker --version
```

or

```bash
docker version
```

---

## 19. Display Docker System Information

Shows detailed information about your Docker installation.

### Command

```bash
docker info
```

---

## 20. Remove Unused Docker Resources

Deletes unused containers, networks, images, and cache to free disk space.

### Command

```bash
docker system prune
```

To remove everything, including unused images:

```bash
docker system prune -a
```

> **Warning:** This permanently deletes unused Docker resources.
